# M0 baseline protection

Baseline Git reference: `v0.1-baseline`, commit `5c4aa72db58108ec482cd9d0e28086c28563f410`.
The existing repository already satisfies the snapshot requirement; Janga is unchanged.

Fresh baseline execution: **962 checks, zero failures**, across all 17 suites
(33 rate/suite combinations). Configuration snapshots, complete console results
and one successful JSONL session per original scenario are archived in
`docs/baselines/v0.1/`. `docs/validation/m0/results.json` records the same 962
passing checks after adding disabled feature flags and read-only instrumentation.
The extra instrumentation suite passes 5 checks at each frequency.

All five proposed v0.2 feature flags initially default OFF. No force, spring,
reach, launch or collision tuning changed. M2–M6 remain unimplemented.

Optional capture recording samples simulation input, per-hand world/local
contacts, actual/desired reach, relative velocity, support identity, force,
failure reason, body velocities, features, frame cost and FPS to
`user://capture_frames.jsonl`. Recording is off by default and produces no body
forces or pose/velocity writes. A teardown reference guard was added after the
dynamic launch isolation fixture exposed a freed-level access in the new logger;
both launch rates were rerun successfully after that instrumentation-only fix.

Rendered MCP Pro replay exercised static, swing and reactive scenes with flags
OFF; its snapshots and representative sampled frames are archived alongside
the baseline. This is an interactive engine replay, not a new human feel rating.
