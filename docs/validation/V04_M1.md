# v0.4 M0 and M1 gate

M0 baseline: commit `33bd175`, protected configuration/specification at `9b05264`.
The prior contextual prototype retains 1,746 passing checks and 13 native
checks per frequency. Its shared mouse input was rejected as a solution to
the aiming conflict; the record is preserved rather than labelled successful UX.

M1 adds opt-in profile 3 with the pointer used only for surface selection.
The existing profile 2 startup remains unchanged. Prior profiles 0/1/2 remain
selectable. Hold-to-grip is mandatory in profile 3; Space comparison defaults OFF.
Variant A retains the initialized arm lengths. No mouse-drag, contextual effort
or virtual-hand target API is called from its physics input branch.

| Check | Prior shared input | Independent aim / A |
|---|---|---|
| Vertical aim changes supporting target | Yes, by design | No |
| Aim during finite reach retargets anchor | No | No |
| MMB moves arm targets | No | No |
| Mouse-up over UI releases only its hand | Yes | Yes |
| W drives direct length change | In baseline 0 only | No: supported swing |
| Integrated checks at 60/120 Hz | Preserved prior suites | 24/24 each |

Actual console logs are in `v04_m1/`. The physics specialist additionally
reported its first 10/10 HOLD_LENGTH checks at each frequency before adding
B/C. This gate establishes input independence, not climbing usefulness.

Changed files: `grip_up_lab.gd` adds the profile branch, policy/feature controls,
help text and aim-independence log marker. `test_independent_input.gd` verifies
actual held mouse input. The physics controller rejects non-independent intent
APIs in profile 3 and initializes the HOLD_LENGTH variant. The underlying mass,
friction, stiffness, damping, reach, hand speed and force/torque caps are unchanged.

An initial test compared an anchor diagnostic before its first physics update;
the assertion now samples the actual material anchor point at button-down.
No collision or physical threshold was weakened to pass that test.
M2 bounded planning and gameplay acceptance remain separate gates.
