# GRIP UP v0.5 — implementation, evidence and decision

Technical implementation and regression validation are complete. The full human-comparison gate remains open. This phase adds diagnosis, controlled posture comparisons, measured supported swing and optional reach/buffer tooling; it does not establish that new assistance feels better.

## Decision

| System | Recommendation | Evidence and limit |
|---|---|---|
| Independent aim, hold-to-grip, finite material contact | KEEP | Mouse only aims; button release always ends its grip/intention. Existing v0.4 remains recoverable. |
| Per-attempt diagnosis and separate reference/swing routes | KEEP | Pose, transit/contact and retention are independently observed; geometry does not grant attachment. |
| P0 suspension | KEEP as default comparison | No new assistance enabled. Reference routes and observed interactive ten-transfer sequence work with P0. |
| P1 support-relative axial twist | KEEP as opt-in | About90% lower rotating-support twist RMS in the measured fixture; static trials unchanged. Human benefit on moving structures unmeasured. |
| P2 support-aware tilt | REJECT as default | More upright, but some catch windows become shorter or disappear and swing work/decay changes. Retained only as a labelled research option. |
| Conservative reach advisory | KEEP as opt-in research | Read-only; finite-arrival unknown and confidence limits explicit. Not a certified catch predictor. |
| Held120ms buffer | REVISE before promotion | Same early press fails OFF and reaches real contact ON in calibration; no extra reach/strength. Human fairness/agency comparison pending. |
| Overall new default climbing feel | REVISE | Do not promote from automated feasibility alone. |

## Delivered behavior

The preserved startup is profile2; independent aim is explicit profile3. Controls/05 opens the basic ten-transfer route and Controls/06 opens a separate swing-required route. The basic wall has eleven painted guides, configurable.08–.16m spacing (default.12); these are not grip sockets. Every valid wall surface can still be selected. The reference tests use.12 and.14m spacing consistently across P0/P1/P2. The original four scenes remain available.

Mouse movement in profile3 never changes arm length, plans or effort. LMB/RMB remain held grips; MMB orbits, wheel dollies and WASD walks or requests supported swing. Acquiring/releasing one hand retains the other's material point. Optional Space and physical feet remain OFF. Existing A/B/C length policies remain distinct from P0/P1/P2 attitude variants.

New flags `transfer_assist_enabled`, `reach_prediction_enabled`, `catch_buffer_enabled` default OFF; `posture_variant=0`. The new buffer duration defaults.12s and is explicitly adjustable.10–.15. The old predictive comparison remains available, with legacy.15s duration restored outside the new independent-aim buffer. Turning on advisory alone never turns on physical prediction/buffering.

P1 refines an existing finite axial moment; P2 crossfades the existing limited tilt preference. Neither adds an unlimited orientation lock. Dynamic supports receive equal/opposite reactions through actual allocation × engagement weights. No feature writes attached body pose/velocity, points the torso at the mouse, increases reach/strength, or duplicates total effort for two hands.

## Physical limits

Single-grip orientation authority is a bounded gripper-moment approximation, not a free ball joint. Prediction extrapolates current COM velocity/spin, gravity and known force over a short horizon; future contacts, hinge constraints, support acceleration and player actions are unknown. Confidence is reduced accordingly. Sampled shoulder intervals do not certify future path clearance. Outward catch-load warnings use an optimistic instantaneous stopping-work bound and never deny/authorize physical attachment. Sampled/incremental work is not a complete conservation account of gravity, contacts, drag and all support energies.

The adverse front-face swing attempt remains archived; aiming at an obstructed surface still fails. P2's poorer window evidence remains visible. No negative result was removed to present higher completion counts. The technical build is ready for the remaining human comparison; the whole game and future spec milestones are not represented as complete.
