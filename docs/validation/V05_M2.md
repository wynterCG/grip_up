# v0.5 M2 — bounded posture comparison

P1 improves the rotating-support twist fixture; P2 is **rejected as a default improvement**. No force, reach, hand speed, mass, gravity, route geometry or existing length-planner gain was increased. Human comparison of these variants remains pending.

The baseline is M1 `db6ea96`; the isolated P1 snapshot is `21d896b` on `snapshot/v0.5-p1`. P0 preserves v0.4 suspension. These variants are distinct from arm-length policies A/B/C. New assistance is OFF by default and only runs in independent-aim profile3 when explicitly enabled.

P1 changes only the existing axial twist reference and relative twist rate. It transports the reference with observed material support rotation, preserving continuity across one/two/one grips. It keeps the existing16 Nm/rad spring and3 Nms/rad damping, blends over.20s, and limits transported reference speed to2.5rad/s. Opposite moments use the existing actual allocation × engagement reaction weights. All assistance still shares20Nm, within150Nm resultant and360N total hand budgets. Static P0/P1 trials are exactly identical. The free rotating-support twist RMS falls from1.329 to.1265rad at120Hz and1.334 to.1209 at60Hz. Closed-system linear/angular momentum errors remain below4e-6/2.5e-4 in the tested fixture.

The measured residual was roll, not twist. P2 therefore studied a support-aware gravity-up preference using actual anchors, body geometry and load; it never sees the cursor or next route point. Its.25s blend, .8rad/s target speed,3rad/s² target acceleration and.10s authority fade reuse/crossfade the previous12/1.2/.8 tilt block, rather than stacking a motor. Slip, infeasibility, saturation and manual effort stop/fade advancement. This produces a more upright torso without a reliable capture benefit:

| Same fixture |120Hz P0/P1 → P2 |60Hz P0/P1 → P2 |
|---|---:|---:|
| HOLD neutral tilt RMS |.3732 → .2672rad |.3726 → .2664rad |
| HOLD rolled tilt RMS |.4151 → .3045rad |.4138 → .3022rad |
| Rolled free-shoulder window |.175 → .0667s |.1667 → 0s |
| Existing policyB free-shoulder window |.625 → .517s |.567 → .550s |

P2 also changes passive decay and pump work; a smaller tilt cannot be presented as unchanged pendulum behavior. It remains an explicitly labelled research option. P1 remains useful for moving supports, not evidence of a better fixed-wall climb.

Validation: `test_posture_study` passes110 checks at each60/120Hz, including finite transitions, dynamic equal/opposite reactions, slip/saturation, asymmetric dual engagement and no airborne assistance. `test_transfer_routes -- --p1` and `--p2` each pass14 checks per frequency, completing both.12/.14m ten-transfer routes with the same geometry, finite hand travel and existing strength. Timings remain essentially unchanged; this is no demonstrated improvement in human agency.
